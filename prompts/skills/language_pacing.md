## Що оцінювати

### Жаргон та клінічна мова
- Терапевт вживає терміни без пояснення: «когнітивна реструктуризація», «інтеграція», «ресурсний стан»
- Клінічні слова замість простих: «депресивна симптоматика» замість «відчуття пригніченості»
- Акронімі (CBT, DBT, ACT) без пояснення кому вони можуть бути незнайомі

### Довжина реплік терапевта
- Занадто довгі репліки (3+ речень) у фазі дослідження — клієнт «губиться»
- Монологи замість діалогу
- Підрахунок слів: якщо терапевт говорить більше ніж клієнт — це red flag

### Темп (pacing)
- Питання задаються одне за одним без паузи — «допит»
- Перехід до нової теми до завершення попередньої
- Клієнт не встиг закінчити думку — терапевт перебив або доповнив

### Складність синтаксису
- Подвійні питання: «Як ви себе почуваєте і що думаєте про стосунки?» — клієнт відповідає тільки на одне
- Питання з вбудованою передумовою: «Коли ви почали розуміти що це депресія?» — клієнт може не погоджуватись
- Риторичні питання де очікується конкретна відповідь

### Авторитарний тон
- «Треба», «потрібно», «ви маєте», «рекомендую» без запиту на бажання клієнта
- Нав'язливі переконання: «насправді це...», «правда в тому що...»

### Позитивне: правильна мова
- Проста, конкретна мова на рівні клієнта
- Метафори клієнта підхоплені та використані
- Перефразовування без перекручення

## Формат відповіді

Поверни **тільки** JSON. Кожен `quote` — дослівно з рядка `line`, не перефразовуй. Кожен масив — максимум 3 найважливіші елементи (бюджет ~800 токенів; краще 3 влучні ніж 8 обрізаних):

```json
{
  "caught": true,
  "languageIssues": [
    {
      "line": 13,
      "quote": "Це класична депресія, мабуть, з рисами руминації",
      "type": "clinical_jargon_and_premature_diagnosis",
      "analysis": "«Руминація» — незнайоме слово для більшості. Плюс це твердження, не запитання — терапевт переходить до висновку."
    }
  ],
  "doubleQuestions": [],
  "therapistDominance": false,
  "avgTherapistTurnLength": "medium",
  "positives": [
    { "line": 3, "quote": "Розкажіть детальніше", "analysis": "Лаконічне запрошення — дає клієнту простір." }
  ],
  "recommendation": "L13 — клінічний жаргон і передчасний висновок. Фідбек: як перефразувати без діагнозу: «Ви описуєте думки, які кружляють по колу — як це переживається у тілі?»"
}
```
